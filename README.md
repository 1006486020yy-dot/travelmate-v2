# TravelMate V2.3

本版本以 TravelMate V2.2.2 Date Final Fixed 为基准，只做功能增强，不重新设计 UI。

## 本版完成
- 保留 iOS / Apple Glass 毛玻璃视觉与日期顺序逻辑
- 我的行程：9/28 → 9/29 → 9/30 → 10/1 → 10/2 → 10/3 → 10/4
- 方案 A：福州 → 平潭 → 泉州 → 厦门
- 方案 B：福州 → 平潭 → 厦门
- 四城景点补齐：福州、平潭、泉州、厦门
- 四城美食完整收录你提供的店铺
- 景点支持：复制地址 / 导航 / 加入行程 / 收藏
- 美食支持：搜索 / 复制地址 / 导航 / 加入行程 / 收藏
- 行程支持：编辑、添加、本地保存
- AI 保持自由对话式入口，不强制固定模板

## 打开
直接双击 index.html 即可本地预览。
